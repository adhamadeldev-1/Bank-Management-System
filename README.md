# Bank Management System

A console-based banking system developed using C++.

This project simulates the main operations of a bank through a menu-driven console application. It allows users to manage bank clients, perform transactions, manage system users, and work with different currencies.

## Main Features

### Client Management
- Add new clients
- Update client information
- Delete clients
- Find clients
- List all clients

### Transactions
- Deposit money
- Withdraw money
- Transfer money between clients
- View transfer history
- Show total balances

### User Management
- Add new users
- Update users
- Delete users
- Find users
- List users
- User login and logout
- Control user permissions

### Currency Management
- List currencies
- Find currencies
- Update currency exchange rates
- Currency calculator
- Change currency rates

### Other Features
- Data is stored using text files
- Passwords and PIN codes are encrypted before being stored
- Input validation is used throughout the application
- The project is divided into multiple classes to keep the code organized

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Classes and Inheritance
- Encapsulation
- Enums
- Vectors
- String Manipulation

## Project Structure

The project is divided into different classes, where each class is responsible for a specific part of the system, such as clients, users, transactions, currencies, authentication, and different application screens.

## Purpose

I built this project to practice C++ and Object-Oriented Programming by applying the concepts I learned to a complete banking system.

It also helped me gain more experience with file handling, class design, inheritance, data validation, and building a larger console application.
